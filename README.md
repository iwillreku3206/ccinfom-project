# CCINFOM Project - Inventory Items Database
![Static Badge](https://img.shields.io/badge/AY2425--T1-CCINFOM-red)

An *Information Management* (CCINFOM) Project; a database application that searches and edits through inventory items in a gaming market mimicking those found in virtual market economies like *Steam Community Market*.

**Authors**: *Lee*, *Campo*, *David*, *Go*

# Installation
To install dependencies:
```bash
bun install
```

To run:
```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.1.29. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
